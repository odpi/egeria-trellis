## Create Governance Action Process Step
### Display Name
Repo Scouting Scan — Repo Homepage

### Qualified Name
GovActionProcessStep::RepoCoarseScout::repo_homepage

### Description
Finds where the project's homepage and its documentation are, and whether the documentation answers. Reads GitHub's homepage field, the packaging manifests (pyproject.toml, package.json, setup.cfg, Cargo.toml, pom.xml) and the README -- small files only, through the GitHub contents API, never a download -- and keeps the source and the other candidates for each answer. An entry labelled Documentation wins; placeholders such as example.com are rejected. One bounded request records whether the docs URL is reachable. Surfaced in Scouting as links with a short cue; the homepage is published to Egeria as an ExternalReference linked to the repo.

### Produced Guards
survey-completed, survey-invalid, survey-failed, Any

### Ignore Multiple Triggers
true

### Additional Properties
| Parameter Name | Parameter Value |
|---|---|
| executes_at | resource-explorer |
| supported_technology_type | Git Repository |
| re_analysis_step | repo_homepage |

## Create Governance Action Process
### Display Name
Repo Scouting Scan

### Qualified Name
GovActionProcess::RepoCoarseScout

### Description
Fast, GitHub-API-only pass — is this repo active enough to look closer at? Regenerated by scripts/generate_repo_survey_definition.py. Re-authored after the original live Egeria element was lost to a platform restart (quickstart platform does not persist custom-authored elements across restarts). Renamed from 'Repo Coarse Scout' (docs/survey-model.md (§6) D5), then from 'Git Statistics Survey' (2026-08-27) — that name came from its first step, repo_git_statistics, which is a prerequisite refresh step with no results view, so the survey was named after the one thing it cannot show you — qualified_name unchanged, so this is an in-place rename of the existing element, not a new one.

### Additional Properties
| Parameter Name | Parameter Value |
|---|---|
| supported_technology_type | Git Repository |
| survey_kind | scouting |
