### Description
Every catalog-intent: analysis Postgres database analysis: value sampling and data-class/reference-data matching (postgres_column_profile), nested JSON/JSONB/XML column profiling (postgres_nested_columns), the derived-from-stored-rows analyses (db_derived: schema_conventions, db_change_rates, schema_diff, grant_change), and the operations bundle's analysis-tier member (db_external_dependencies, via postgres_operations — see that step's own note in this CSV for why it is chained into more than one Survey Definition).
