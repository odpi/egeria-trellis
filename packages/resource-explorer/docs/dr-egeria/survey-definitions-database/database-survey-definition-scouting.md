## Create Governance Action Process
### Display Name
Database Scouting Scan

### Qualified Name
GovActionProcess::DatabaseScoutingSurvey

### Description
The fast, catalog/read-tier pass over a Postgres database — schema inventory (schema_inventory), row counts (row_count_snapshot), credential visibility (credential_capability), and the operations bundle's scouting-tier half (db_activity_signals, db_resilience). Regenerated by scripts/generate_database_survey_definition.py. postgres_operations also backs an analysis-tier analysis (db_external_dependencies) and an assessment-tier one (privilege_audit) that this step cannot be split apart from — it is chained into all three Survey Definitions (Scouting, Analysis, Assessment) as a result, each under its own qualified name, so each document's ScopedBy links only claim the questions its own analyses answer.

### Additional Properties
| Parameter Name | Parameter Value |
|---|---|
| supported_technology_type | PostgreSQL Database |
| survey_kind | scouting |
